painting-arithmetic · interpretability live

Watch the network forget how to count

The model paints its answer through a 256-d trunk vector t sitting between the shared CNN encoder and the ConvTranspose decoder. Below the stage, seven knowledge-removal interventions edit t (or its inputs) before decoding: zero individual units, ablate the circuit responsible for an entire operator, project out the operator subspace INLP-style. The model re-paints in real time after every change.

2 · operator-circuit lesion

Zero every trunk unit tagged to an operator. The network forgets how to perform that operation while staying competent at the others.

3 · random vs surgical

Kill the same number of units two ways: ranked by operator-purity (surgical) vs uniformly at random. Surgical lesions wreck a single operator; random lesions just degrade everything a little.

N 0

4 · cumulative purity slider

Kill the top-k most operator-pure units globally (across all operators). Past ~80 the model collapses into garbage strokes — the trunk is mostly operator-tagged.

k 0

5 · input-slot blinding

Black out one input image — the slot's 64-d embedding collapses to "blank canvas" features. The model still tries to paint, but with one slot it's hallucinating.

6 · INLP per-op erasure

Project t orthogonal to one operator's centroid direction. The unit cells stay alive; the model loses the concept of "this is operator X" along that axis.

7 · rank-k operator-subspace erasure

INLP all the way: SVD the centred operator centroids and project out the top-k singular directions. k = 3 kills the full operator subspace (only 3 d.o.f. for 4 ops). + and × converge to the same painted result.

k 0
